# Emploi Rapide

Site d'offres d'emploi en Afrique francophone et dans le monde, mis à jour chaque matin : https://emploirapide24.com

- `index.html` : application (installable, fonctionne hors connexion)
- `data.json` : offres du jour
- `offre/` : une page par offre (partage WhatsApp, Google for Jobs)
- `sitemap.xml`, `robots.txt`, `CNAME` : référencement et domaine
